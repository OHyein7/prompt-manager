# 나만의 프롬프트 관리 프로그램

Python으로 만든 콘솔 기반 프롬프트 관리 프로그램입니다.

자주 사용하는 프롬프트를 카테고리별로 관리하고, 검색 및 즐겨찾기 기능을 이용할 수 있도록 만들었습니다.

## 개발 환경

- Python 3.14
- VSCode
- Git
- GitHub

## 실행 방법

1. Python을 설치합니다.
2. 프로젝트 폴더를 엽니다.
3. 터미널에서 아래 명령어를 실행합니다.

```bash
python main.py
```

## 주요 기능

### 1. 프롬프트 추가

새로운 프롬프트의 제목, 내용, 카테고리를 입력하여 추가할 수 있습니다.

### 2. 프롬프트 목록

등록된 모든 프롬프트를 번호와 함께 확인할 수 있습니다.

### 3. 카테고리별 조회

원하는 카테고리를 선택하여 해당 카테고리의 프롬프트만 확인할 수 있습니다.

### 4. 프롬프트 검색

검색어를 입력하여 프롬프트의 제목 또는 내용에서 원하는 프롬프트를 검색할 수 있습니다.

### 5. 프롬프트 상세 보기

프롬프트의 제목, 카테고리, 즐겨찾기 상태 및 전체 내용을 확인할 수 있습니다.

### 6. 즐겨찾기 관리

프롬프트를 즐겨찾기에 추가하거나 해제할 수 있습니다.

### 7. 즐겨찾기 목록

즐겨찾기로 설정한 프롬프트만 모아서 확인할 수 있습니다.

## 프롬프트 카테고리

- 텍스트 생성
- 이미지 생성
- 영상 생성
- 페르소나
- 자동화
- 기타

## 데이터 저장 방식

프롬프트 데이터는 Python의 리스트와 딕셔너리를 사용하여 저장합니다.

프로그램 실행 중에는 추가하거나 변경한 데이터가 유지되지만, 프로그램을 종료하면 초기화됩니다.
