# 나만의 프롬프트 관리 프로그램

Python으로 만든 콘솔 기반 프롬프트 관리 프로그램입니다.

자주 사용하는 프롬프트를 카테고리별로 관리하고, 검색 및 즐겨찾기 기능을 이용할 수 있도록 만들었습니다.

## 개발 환경

- Python 3.14
- VSCode
- Git
- GitHub

## 실행 방법

1. Python을 설치합니다.
2. 프로젝트 폴더를 엽니다.
3. 터미널에서 아래 명령어를 실행합니다.

```bash
python main.py
```

## 주요 기능

### 1. 프롬프트 추가

새로운 프롬프트의 제목, 내용, 카테고리를 입력하여 추가할 수 있습니다.

### 2. 프롬프트 목록

등록된 모든 프롬프트를 번호와 함께 확인할 수 있습니다.

### 3. 카테고리별 조회

원하는 카테고리를 선택하여 해당 카테고리의 프롬프트만 확인할 수 있습니다.

### 4. 프롬프트 검색

검색어를 입력하여 프롬프트의 제목 또는 내용에서 원하는 프롬프트를 검색할 수 있습니다.

### 5. 프롬프트 상세 보기

프롬프트의 제목, 카테고리, 즐겨찾기 상태 및 전체 내용을 확인할 수 있습니다.

### 6. 즐겨찾기 관리

프롬프트를 즐겨찾기에 추가하거나 해제할 수 있습니다.

### 7. 즐겨찾기 목록

즐겨찾기로 설정한 프롬프트만 모아서 확인할 수 있습니다.

## 프롬프트 카테고리

- 텍스트 생성
- 이미지 생성
- 영상 생성
- 페르소나
- 자동화
- 기타

## 데이터 저장 방식

프롬프트 데이터는 Python의 리스트와 딕셔너리를 사용하여 저장합니다.

프로그램 실행 중에는 추가하거나 변경한 데이터가 유지되지만, 프로그램을 종료하면 초기화됩니다.

코드 구조

프로그램의 기능을 각각의 함수로 분리하여 관리했습니다.

show_menu() : 프로그램의 메뉴를 출력합니다.
add_prompt() : 제목, 내용, 카테고리를 입력받아 새로운 프롬프트를 추가합니다.
show_list() : 등록된 모든 프롬프트를 목록으로 출력합니다.
show_by_category() : 선택한 카테고리의 프롬프트만 출력합니다.
search_prompt() : 제목 또는 내용에 포함된 키워드로 프롬프트를 검색합니다.
show_detail() : 선택한 프롬프트의 상세 정보를 출력합니다.
manage_favorite() : 프롬프트의 즐겨찾기를 추가하거나 해제합니다.
show_favorites() : 즐겨찾기로 설정된 프롬프트만 출력합니다.

기능별로 함수를 분리하여 코드의 가독성과 유지보수성을 높였습니다.

데이터 구조 설계

프롬프트 데이터는 리스트 안에 딕셔너리를 저장하는 방식으로 구성했습니다.

prompts = [
    {
        "title": "영어 학습 자료 만들기",
        "content": "중학생 영어 학습자를 위한 학습 자료를 만들어주세요.",
        "category": "텍스트 생성",
        "favorite": False
    }
]
리스트를 사용하는 이유

여러 개의 프롬프트를 순서대로 저장하고 반복문을 이용하여 전체 데이터를 쉽게 조회할 수 있다는 장점이 있습니다.

단점은 특정 프롬프트를 제목이나 ID로 바로 찾는 경우 검색 과정이 필요하다는 점입니다.

딕셔너리를 사용하는 이유

각 프롬프트의 title, content, category, favorite처럼 서로 다른 정보를 의미 있는 키로 관리할 수 있습니다.

단점은 동일한 구조의 딕셔너리가 반복되어 데이터가 많아질 경우 관리해야 할 정보가 많아질 수 있다는 점입니다.

반복문 설계

프로그램의 메인 메뉴는 while True 반복문을 사용합니다.

사용자가 기능을 선택하면 해당 기능을 실행한 후 다시 메뉴로 돌아오도록 설계했습니다.

사용자가 0. 종료를 선택하면 break를 실행하여 반복문을 종료합니다.

이를 통해 프로그램을 종료하기 전까지 메뉴를 계속 사용할 수 있도록 구현했습니다.

브랜치 전략

프롬프트 추가 기능은 main 브랜치와 분리된 feature/add-prompt 브랜치에서 작업했습니다.

기능별로 독립적인 브랜치에서 작업하면 기존 main 브랜치의 안정적인 코드를 유지하면서 새로운 기능을 개발할 수 있습니다.

기능 구현이 완료된 후 커밋하고 main 브랜치로 checkout한 뒤 merge하여 기능을 통합했습니다.

커밋 전략

기능이나 작업 단위로 커밋을 나누어 변경 이력을 쉽게 확인할 수 있도록 했습니다.

커밋 메시지는 변경 내용을 알 수 있도록 다음과 같은 형식을 사용했습니다.

feat: 새로운 기능 추가
fix: 오류 수정
docs: README 등 문서 수정
chore: 프로젝트 초기 설정 등 기타 작업

예시:

feat: add prompt creation
feat: add prompt search
feat: add favorite management
fix: restore prompt search function
docs: update README

기능 하나를 완성할 때마다 의미 있는 단위로 커밋하는 것을 기준으로 했습니다.

데이터 영속화 설계

현재 프로그램의 프롬프트 데이터는 메모리에 저장되며 프로그램을 종료하면 초기화됩니다.

향후 데이터를 영구적으로 저장해야 한다면 JSON 형식을 사용하는 것을 권장합니다.

JSON은 Python의 리스트와 딕셔너리 구조를 그대로 표현하기 쉽고, 별도의 데이터베이스 설치 없이 파일로 저장할 수 있다는 장점이 있습니다.

데이터 규모가 커지고 복잡한 검색이나 여러 사용자의 동시 접근이 필요해진다면 SQLite와 같은 데이터베이스를 사용하는 방법도 고려할 수 있습니다.

중복 프롬프트 처리 규칙

현재 프로그램은 프롬프트 제목의 중복을 허용합니다.

동일한 제목의 프롬프트가 추가되더라도 기존 데이터를 덮어쓰지 않고 각각 별도의 프롬프트로 저장합니다.

향후 데이터가 커질 경우에는 각 프롬프트에 고유 ID를 부여하여 동일한 제목의 프롬프트도 구분할 수 있도록 개선할 수 있습니다.
